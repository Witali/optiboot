# Инструкция по настройке и прошивке Arduino Nano (ATmega328PB) в Linux

Данное руководство составлено на основе диагностики вашей платы. 

### Спецификация вашего устройства:
* **USB-UART Чип:** FT232R (или его точный функциональный клон). Определяется в Linux как `ID 0403:6001`. Родной драйвер: `ftdi_sio`.
* **Микроконтроллер:** ATmega328PB (модернизированная версия классического 328P с сигнатурой `0x1e9516`).
* **Особенность платы:** Ножки №3 и №6 физически разведены на GND и VCC для обратной совместимости по питанию. Пины PE0 и PE1 аппаратно заблокированы, но пины **PE2 (A6)** и **PE3 (A7)** работают как полноценные цифровые выводы.

---

## Часть 1. Настройка Arduino IDE

Для корректной работы со всеми функциями чипа ATmega328PB необходимо установить стороннее ядро **MiniCore**.

### Шаг 1: Добавление репозитория
1. Откройте Arduino IDE.
2. Перейдите в **Файл** -> **Настройки** (File -> Preferences).
3. В поле **Дополнительные ссылки для Менеджера плат** вставьте адрес:
   `https://mcudude.github.io/MiniCore/package_MCUdude_MiniCore_index.json`
4. Нажмите **ОК**.

### Шаг 2: Установка MiniCore
1. Перейдите в **Инструменты** -> **Плата** -> **Менеджер плат...** (Tools -> Board -> Boards Manager...).
2. Введите в поиске `MiniCore`.
3. Найдите пакет от **MCUdude** и нажмите **Установить** (Install).

### Шаг 3: Конфигурация меню «Инструменты» (Tools)
Выставите следующие настройки строго под вашу конфигурацию:
* **Плата (Board):** MiniCore -> ATmega328
* **Variant:** 328PB
* **Clock:** 16 MHz external
* **Compiler LTO:** Enabled *(Рекомендуется для оптимизации размера и скорости)*
* **Bootloader:** No Bootloader *(Критически важно! Решает проблему ошибки Optiboot 8.3)*
* **Порт (Port):** `/dev/ttyUSB0` (или ваш актуальный порт)

## Часть 2. Прошивка через консоль (avrdude)

Поскольку на плате отсутствует стандартный загрузчик (или используется Optiboot 8.3, вызывающий ошибку `bootsize`), прошивка напрямую в среде через режим «No Bootloader» или из консоли выполняется с указанием конкретного типа чипа.

### Команда для проверки связи и считывания сигнатуры:
```bash
avrdude -c arduino -p m328pb -P /dev/ttyUSB0 -b 115200 -v
```

### Команда для прямой прошивки готового `.hex` файла:
```bash
avrdude -c arduino -p m328pb -P /dev/ttyUSB0 -b 115200 -U flash:w:имя_файла.hex:i
```

## Часть 3. Оптимизация кода (Compile-Time GPIO)

Стандартные функции `digitalWrite` и `digitalRead` работают в рантайме и тратят много тактов процессора. Чтобы вычисления происходили на этапе компиляции, используйте библиотеку **FastGPIO** (доступна в Менеджере библиотек).

### Пример кода для работы с пином A6 (PE2) на вашей плате:
```cpp
#include <FastGPIO.h>

// Для вашей платы пины A6 и A7 — это полноценные цифровые GPIO (PE2 и PE3)
const uint8_t ledPin = A6; 

void setup() {
  // Установка пина на выход в режиме compile-time (всего 1 макрокоманда)
  FastGPIO::Pin<ledPin>::setOutput(low);
}

void loop() {
  // Переключение состояния пина за 1 машинный такт
  FastGPIO::Pin<ledPin>::toggle(); 
  delay(500);
}
```

## Часть 4. Безопасность и нюансы
1. **Фьюзы (Fuses):** Режим «No Bootloader» при обычной загрузке скетчей **не изменяет фьюзы**. Прошивка безопасна, чип невозможно испортить кодом.
2. **Пины PE0 и PE1:** Попытка программно перевести пины 22 и 23 (`PE0`/`PE1`) в режим `OUTPUT` не повредит чип аппаратно благодаря встроенным ограничительным цепям, но физически они работать не будут, так как припаяны к линиям питания платы.
