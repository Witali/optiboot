# План первичных испытаний на реальном ATmega328P

**Пока ни одного аппаратного теста с данной прошивкой не проведено.** Ниже — безопасный план для следующего агента/разработчика, а не отчёт о проделанном.

1. Использовать запасную Arduino Uno или отдельный ATmega328P с тактовым источником 16 MHz; подготовить **рабочий ISP-программатор** для восстановления.
2. Перед первым изменением сохранить **весь доступный дамп Flash, EEPROM, fuse и lock битов** через ISP; проверить BOOTSZ/BOOTRST, частоту и BOD, сохранить оригинальный рабочий Optiboot. Не менять фьюзы «наугад».
3. Записать текущий HEX именно в boot-секцию (он уже адресован `0x7E00`); прочитать обратно через ISP и побайтно сравнить. Не писать `.bin` с нулевого адреса.
4. Проверить включение питания и внешний сброс; убедиться, что через DTR/RTS/RESET загрузчик запускается, а по истечении WDT происходит переход к приложению.
5. Запустить штатный `avrdude -c arduino -p m328p -b 115200 -P <port>`: GET_SYNC, GET_PARAMETER, READ_SIGN, READ_PAGE/PROG_PAGE, стандартный verify. Отдельно испытать потери/ошибки кадров UART и неверный EOP с заведомо ненужным приложением.
6. EEPROM: сначала резервная копия; проверить чтение без изменений. На запасном MCU записать контрольный паттерн по адресам 0..1023 блоками 16 Б и проверить чтением/verify после перезагрузки. Проверить границы (0x000, 0x1FE, 0x200, 0x3F0).
7. Flash: на запасном MCU проверить запись всех обычных страниц, частичных последующих страниц и последней страницы **приложения** перед `0x7E00`; убедиться, что boot-раздел не меняется. Проверить EOP bad/truncated packet, выровненность адреса, RWW ре-активацию.
8. Fuse/lock: сравнить четыре read-only результата `UNIVERSAL` с ISP-программатором; **никогда не проверять запись fuse/lock через bootloader**.
9. Проверить питание: коричневый сброс и исчезновение питания во время записи Flash/EEPROM могут повредить данные даже при правильном коде; такие сценарии только на запасном MCU с BOD и ISP-восстановлением.
10. Записать лог UART, версию avrdude/USB-UART/OS, точные фьюзы, источник тактирования, версию исходника и SHA256 HEX, затем обновить этот архив и документацию.

**Важно:** не вызывать `avrdude -e` через этот UART-загрузчик: `CHIP_ERASE` и соответствующий UNIVERSAL запрос не реализуют физическое стирание, даже если ACK присутствует. Запись fuse/lock — только через подходящий ISP/HV-программатор.
