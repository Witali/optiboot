# Последовательность запросов пользователя и принятых решений

Это восстановленная из доступного диалога **хронология формулировок пользователя** (не полная буквальная стенограмма всех ответов ассистента). Основная техническая история с решениями, ошибками, размерами и файлам — `02_CHANGELOG_HISTORY_RU.md`.

1. **Поиск и минимизация:** «А найди загрузчик для Ардуино Optiboot, скачай его исходники и постарайся оптимизировать размер еще уменьшить его» → исследование оригинального GitHub, начальные 410/402 Б.
2. **Сравнение и протокол:** «А сравни наш ассемблерный код с оригинальным оптибудом. Подумай, что можно ещё упростить, улучшить для минимального размера. И проверь, что протокол соответствует точно оригинальному» → дифференциальные проверки, исправления WDT/FE0, 368/366 Б.
3. **SRAM:** «Так ты уже сделал без RAM буфера?» → подтверждение аппаратного SPM-буфера вместо SRAM для Flash (начиная с 368-байтного этапа).
4. **Дальнейшее сокращение:** «А что еще можно оптимизировать в этой прошивке?» → 358/356/350 Б, оценка trade-off reset-only.
5. **Дополнительные возможности:** «А какие функции можно добавить, может быть по протоколу программирования есть какие-то функции, которые не добавлены?» → инвентаризация STK500v1, диагностические 480/511 Б.
6. **Нужные avrdude команды:** «А выбери команды, которые наиболее перспективные и нужны, желательно нужны для этого программатора» → приоритет EEPROM read/write (`PROG_PAGE`, `READ_PAGE`) и ограниченный UNIVERSAL.
7. **EEPROM сначала:** «Ну давай для начала сделаем команды, которые для работы с EEPROM» → 498 Б, 16-байтный приём в SRAM с EOP-проверкой до записи.
8. **Уместить UNIVERSAL:** «А можно ли это ещё оптимизировать, чтобы у нас дополнительные функции влезли, поместились? Может быть 0x56 универсал?» → буфер EEPROM на стеке, 508 Б, четыре fuse/lock READ.
9. **Аудит чипа и протоколов:** «Проверь, что все протоколы были корректно соблюдены и соответствуют спецификациям на чип DataSheet.» → исправление `SPM Page Write Z PCWORD=0`, финальная 512 Б, подтверждённое ограниченное соответствие.
10. **Передача проекта:** «Собери все наши исследования, историю изменений прошивки в отдельный архив для передачи другому агенту» → этот архив.

**Не путать смежные проекты:** Optiboot — загрузчик ATmega328P по UART/STK500v1. Другой проект пользователя Micronucleus Block64 — загрузчик ATtiny88 по V-USB со своим протоколом; он не является продолжением данного кода.
