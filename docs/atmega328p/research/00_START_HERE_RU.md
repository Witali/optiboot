# Optiboot Mini ATmega328P — полный архив исследования для передачи агенту

**Дата фиксации:** 28 октября 2026 г.  
**Ветка проекта:** отдельная от Micronucleus Block64; не смешивать протоколы, исходники и ограничения.  
**Язык материалов:** русский, код AVR Assembly, Python 3.

## Откуда начинать

1. **Актуальный экспериментальный исходник:** `CURRENT/optiboot_328_verified.S`.
2. **Его прошивка:** `CURRENT/optiboot_328_verified.hex`, адреса `0x7E00..0x7FFF`; `CURRENT/optiboot_328_verified.bin` содержит ровно 512 байт без адресной информации.
3. **Главный аппаратный и протокольный аудит:** `CURRENT/AUDIT_RU.md` — обязательно прочитать ПЕРЕД дальнейшей оптимизацией.
4. **Воспроизведение:** `RUN_CURRENT_TESTS.sh`, `01_REPRODUCE_RU.md`, `CURRENT/build.py` и `CURRENT/test_*.py`.
5. **История версий:** `02_CHANGELOG_HISTORY_RU.md` и исходные проекты `HISTORY_SOURCES/`.
6. **Незакрытые проблемы:** `04_TASKS_FOR_NEXT_AGENT_RU.md`; **ограничения протокола:** `03_PROTOCOL_AND_HARDWARE_RU.md`.
7. **Оригинальные, не изменённые предыдущие ZIP:** `ORIGINAL_STAGE_ARCHIVES/` (7 файлов). Все промежуточные источники и журналы сохранены также в `HISTORY_SOURCES/`.

## Последний подтверждённый статус

- Цель: **ATmega328P / Arduino Uno, 16 MHz, аппаратный UART0 115200, STK500v1 (совместимое подмножество), 512-байтный boot-раздел**.
- Последний образ: **510 байт инструкций + 2 байта версии = 512/512 байт**, без свободного места; начало boot `0x7E00`, версия `03 08` на `0x7FFE..0x7FFF`.
- Функциональность: Flash page read/write с аппаратным SPM-буфером **без 128-байтного SRAM-буфера**; EEPROM 1024 байта read/write (пакеты записи 1..16 байт, временно в стеке); выборочные read-only fuse/lock через `UNIVERSAL (0x56)`.
- Восстановлены WDT, UART FE0; добавлена проверка выравнивания Flash Page Write на 128-байтную границу.
- **Тесты прошли только в собственном ограниченном программном интерпретаторе AVR. РЕАЛЬНОЙ платы ATmega328P не было.** 28.10.2026 повторно собраны HEX и BIN из `.S`, SHA256 совпал с сохранёнными образами, заново запущены тесты. См. `TEST_RECHECK_2026-10-28.txt`.
- **Нет полного соответствия AVR061/STK500v1.** Например, `CHIP_ERASE` может быть подтверждён без стирания, `GET_SIGN_ON` возвращает только ACK, high byte длины игнорируется. **Не использовать `avrdude -e` и операции записи fuse/lock через bootloader.**
- **Не прошивать на единственную рабочую плату без ISP-восстановления**, резервных копий и отдельной проверки предохранителей (fuses).
