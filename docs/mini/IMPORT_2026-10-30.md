Following the package's update scope, external `firmware/`, `docs/`,
`verification/`, `handoff/`, `history/`, package-management scripts and nested
archives were not imported. Generated objects, linked ELF files, output
directories and Python caches are excluded. The original C implementation,
main Makefile, protocol headers, stock firmware and existing ATmega328P research
remain unchanged.

## Build compatibility adjustment

The supplied builders reject all relocation records. The installed Clang 18.1.3
and AVR-GCC assemblers emit local branch relocations, so their object files need
a linker step before binary extraction. Both Mini builders now use `avr-ld`
when needed, at section address zero and without linker relaxation. The Intel
HEX records supply the physical boot address. The build rejects missing
relocation-inspection tools and any relocations remaining in the linked image.
Assembly source and reference firmware bytes are unchanged by this adjustment.

## Remaining validation

No physical MCU programming, real UART/AVRDUDE exchange, fuse/lock programming,
oscillator calibration, watchdog timing or SPM/EEPROM latency was tested.
The limited instruction simulator models peripheral completion and does not
replace hardware validation. The new ports remain experimental.
