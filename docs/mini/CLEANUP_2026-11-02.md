# Master integration and historical artifact cleanup

Date: 2026-11-02. The fork's default branch is `master`. The integration combines
its previous tip `ccfc7f9470d9823b945092fb2e2905c193c75ec8` with the tested
Mini/Middle/Full and shared-database work at
`726197577d993165f9942433f3fb08b9ef5b8952`.

## Preserved layout and current implementation

The existing repository directories retain their paths. The original Optiboot
C implementation, board targets, stock HEX files and historical research
directories remain available. The active `optiboot/bootloaders/optiboot/` tree
matches the tested source branch exactly. Include constants remain outside JSON.
The Nano USB test tools and qualified historical image report are included.

The obsolete duplicate README section describing 38 current profiles was
replaced by a short historical-research link. The current build guide describes
39 devices. A duplicate worktree-ignore entry was removed.

## Removed intermediate artifacts

Removed 27 tracked `.o` files from `optiboot/bootloaders/optiboot_328p/` and its
existing `history/` directories, totaling 44,848 bytes in the checkout. For
each file, the adjacent assembly was compiled with Clang, local relocations
were resolved if present, and the extracted binary matched the retained BIN
byte for byte. The assembly and reference BIN/HEX files remain in place.
The current Mini test fixtures are independent oracles and were retained.

The root `.gitignore` now excludes `*.o`, with explicit exceptions for the two
current symbol fixtures and three retained historical objects. This prevents
rebuilt intermediate objects from being accidentally staged.

Three historical objects were retained because the same proof was unavailable:

* `history/02b_all_machine_code_prototypes/upstream_reference.o` did not rebuild
  successfully from the adjacent source with the current tools.
* `history/06_508_eeprom_universal/optiboot_328_eeprom_rw.o` and `out.o` do not
  have matching adjacent source/BIN pairs.

All seven historical ZIPs were retained. Their 128 members include 37 without
an identical copy outside the archives, including documents and tools. The
existing import and archive manifests remain provenance records for their
recorded revisions rather than live checkout inventories.

Git history and the previous master revision are retained. An individual
removed object can be recovered, for example:

```sh
git restore --source=ccfc7f9470d9823b945092fb2e2905c193c75ec8 -- optiboot/bootloaders/optiboot_328p/optiboot_328_verified.o
```

## Validation

The resolved integration passed all 126 instruction-model tests and 27
generator/database tests. The active bootloader tree is identical to the
shared-database revision whose 441 clock images and 79 Clang/GCC pairs passed;
see the [database validation](DEVICE_DATABASE.md).

After the intermediate-file removal, the retained standalone ATmega328P source
rebuilt successfully and all six historical software regression suites passed.

```sh

python3 scripts/atmega328p/run_tests.py --build
```
